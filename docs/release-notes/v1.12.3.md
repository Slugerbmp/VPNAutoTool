**WARP и запрет**
- **WARP через запрет работает так же, как при запуске стратегии из .bat вручную.** Раньше программа исключала серверы WARP из запрета и добавляла свой профиль для WARP — на части компьютеров из-за этого WARP не подключался, хотя с исходным .bat работал. Теперь по умолчанию — как в .bat; прежний вариант включается сам, только если WARP сообщает о подмене пакетов.
- **Запрет снова запускается, если задача запуска испортилась** (антивирус, перенос программы): программа один раз пересоздаёт задачу (попросит права администратора) и повторяет команду.

**VPN**
- **Автоматический тест скорости:** если выбранный сервер не отвечает (или подключение не готово) дольше 15 секунд, программа сама проверяет скорость отвечающих серверов и переключается на самый быстрый.
