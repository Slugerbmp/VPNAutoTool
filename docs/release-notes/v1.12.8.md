# NETtool 1.12.8

- Telegram на телефоне через раздачу. Telegram не пользуется прокси, заданным в настройках Wi-Fi, поэтому раньше не грузился. Теперь в блоке раздачи есть QR «Telegram»: камера телефона откроет Telegram и предложит подключить прокси этого компьютера.
  - Если на ПК запущен TG WS Proxy — телефон идёт через него (как Telegram на ПК), вход 10831.
  - Иначе — SOCKS5 на том же порту раздачи 10830: в режиме VPN — через выбранный сервер, в режиме запрета — с компьютера (через запрет и WARP).
