# NETtool 1.12.5

- Запрет снова включается: задача запуска создаётся по SID пользователя (с именем учётной записи Windows отвечала «Параметр задан неверно»). Если задача всё равно не срабатывает — команда выполняется напрямую с правами администратора (Windows спросит разрешение).
- WARP через запрет: если в сборке запрета фильтр по IP выключен (ipset-all.txt — заглушка), для WARP берётся полный список из ipset-all.txt.backup — как при ручном запуске .bat.
- Ярлык в «Пуске»: при каждом запуске проверяется, что он есть и ведёт на текущий NETtool, ему прописывается тот же идентификатор приложения, что и окну. Значок на панели задач берётся из самого exe.
