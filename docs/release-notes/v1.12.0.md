**VPN Auto теперь называется NETtool.**

- Новое название в окне, трее, меню «Пуск», ярлыках, установщике и в списке программ Windows; на macOS — `NETtool.app`.
- Обновление поверх VPN Auto — без потерь: настройки, подписка, запрет и WARP остаются на месте, старые ярлыки «VPN Auto» заменяются на «NETtool». Папка с программой у уже установленных копий не меняется (там лежит запрет).
- Файлы выпуска: `NETtool-Setup.exe`, `NETtool-macOS.zip`, архив для друзей `NETtool-<версия>.zip`. Под прежними именами выкладываются копии — чтобы обновились программы старых версий.
