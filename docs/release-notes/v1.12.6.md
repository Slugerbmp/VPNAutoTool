# NETtool 1.12.6

- Права администратора — один раз при запуске, а не на каждую кнопку. Если задача планировщика на компьютере не работает, NETtool при запуске один раз спрашивает разрешение и запускает помощника с правами администратора; он выполняет все команды запрета, WARP, шлюза и Защитника до закрытия программы. Там, где задача работает, окон UAC нет вовсе.
- Если нажать «Нет» в окне UAC, NETtool не засыпает повторными запросами.
- Если запрета нет (удалил антивирус), он скачивается при включении.
- Значок на панели задач: новый идентификатор приложения (старый Windows запомнила с пустым значком); он же прописывается ярлыку в «Пуске» и закреплённому значку.
