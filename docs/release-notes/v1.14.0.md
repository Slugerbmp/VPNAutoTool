# NETtool 1.14.0

- Раздел «Сайты»: два списка рядом — «Через обход» и «Исключения». Сайты из «Через обход» всегда идут в обход блокировок: в режиме VPN — через сервер (даже российские домены при «Российские сайты без VPN»), в режиме запрета — через запрет, на приставках и в раздаче — через этот ПК. Списки сразу применяются к приставкам.
- TikTok в раздаче и на приставках: домены TikTok добавлены в обход и всегда идут через зарубежный выход (TikTok не показывает ленту российским адресам) — в том числе в режиме запрета.
- Подключённые устройства: в «Раздать доступ» — список устройств (имя, IP, MAC, через что подключены — прокси, Telegram, DNS, шлюз), трафик и когда были в сети.
- Меню упорядочено: подключение → сайты → раздача и сервисы → правила → настройки (по группам) → диагностика (сначала действия, журналы — под спойлером).
