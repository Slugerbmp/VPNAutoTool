# NETtool 1.12.7

- Режим шлюза для приставок при включённом WARP (или другом VPN со своим адаптером): пересылка включается и на адаптере, через который идёт интернет. Раньше Windows отбрасывала пакеты приставки — PlayStation подключалась к сети, но YouTube и сайты не открывались. Если WARP включили уже после шлюза, пересылка на его адаптере включается автоматически.
- Отдельное правило брандмауэра для приёмника шлюза (TCP 10840) — шлюз работает, даже если раздачу на этом компьютере раньше не включали.
