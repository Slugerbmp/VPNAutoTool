Первый публичный выпуск **VPN Auto** от **undr**.

**Что внутри**
- Автовыбор самого стабильного VPN-сервера из любой подписки: vless, vmess, trojan, ss, hysteria2, wireguard, base64, JSON Xray и sing-box, Clash/Mihomo YAML.
- «Запрет» без VPN (YouTube, Discord, Instagram, Telegram, Кинопаб…) и Cloudflare WARP с автоподбором протокола и порта.
- TG WS Proxy для Telegram Desktop.
- Раздача интернета на телефоны (прокси с QR-кодами), **Xbox и PlayStation**: DNS-режим и **режим шлюза** (весь трафик приставки, включая голос Discord, идёт через компьютер).
- Обход ошибки Xbox **0x80a40401** «регион, где служба недоступна»: вход и службы Xbox идут через зарубежный сервер.
- **Автообновление** с проверкой SHA-256. Это последний выпуск, который нужно ставить вручную.

**Файлы**
- `VPN-Auto-Setup.exe` — установщик для Windows 10/11.
- `VPN-Auto-macOS.zip` — приложение для macOS 11+ (Intel и Apple Silicon).
- `VPN-Auto-1.10.0.zip` — архив для друзей: Windows + macOS + инструкция.
- `SHA256SUMS.txt` — контрольные суммы.
