**Исправления и улучшения**
- **Меньше срабатываний антивирусов.** Установщик больше не содержит внутри сторонних программ (запрет с драйвером WinDivert и TG WS Proxy): программа скачивает их с GitHub авторов при установке. У файлов появились сведения о версии и авторе и стандартный манифест Windows.
- **Значок в «Пуске» и на панели задач больше не пропадает** после обновления: ярлыки берут значок прямо из программы. Уже закреплённые значки установщик чинит сам.
- **VPN не подключается автоматически к серверам из СНГ** (Беларусь, Россия, Казахстан и др.): страна определяется по флагу в названии и по реальному адресу выхода. Такие серверы помечены «СНГ · вручную», выбрать их можно только вручную.
- **«Ядро не принимает соединения» на всех серверах:** если Windows закрепила нужные порты за Hyper-V/WSL, программа сама берёт другой диапазон. Если ядро удалил или блокирует антивирус, программа прямо об этом пишет.
- **WARP:** перед подключением программа запускает службу Cloudflare WARP, если она остановлена.
- **Рамка окна снова в цвет темы** (чёрная/белая).
- **Установщик — в светлой теме.**
